# Maternite

Maternite is a stratification tool for maternal and neo-natal risk that is powered by Artificial intelligence. The platform enables users to collect, analyze, and visualize patients ante-nantal data to facilitate informed decision-making and curb maternal mortality.

# Project Overview

The goal is to create a tool that allows organizations to:
- Collect Antenatal and demographic information
- Stratify risk level based on selected indicators
- Visualize insights through dashboards
- Generate reports for informed decision-making

# Features

- User authentication
- ANC data collection
- Interactive dashboard
- Data visualization
- Report generation
- Search and filtering
- Export reports
